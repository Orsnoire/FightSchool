# Campaign artwork v1

Created October 28, 2026 for PR #90. Original images generated with OpenAI imagegen from the following prompts; no third-party game assets or uploaded reference images were used. Owner approved the landmark direction and requested forests plus all mountain/cave-wall edge combinations. This is the first overworld/normal-cave workshop, not approval of all environment themes.

Runtime assets are in `client/src/assets/campaign-v1/`. `terrain.webp` and `borders.webp` are 2×2 material atlases, retained at the original 1254×1254 size in quality-88 WebP. Each atlas quadrant fills exactly one 48×48 CSS-pixel map cell and repeats at every cell, independent of map dimensions or coordinates. The camera scales the assembled map, including its tiles, together. This is the owner's October 29 correction to the previous map-sized texture sampling. `landmarks.webp` is a transparent 4×2 atlas, exported at 768×384 with nearest-neighbour sampling and lossless WebP. Battle scenes retain original 1672×941 dimensions in quality-88 WebP. Exporting changes encoding/size only; the artwork was generated by imagegen. Keep alpha transparency and pixelated display.

Ground tile geometry is 32 native pixels, displayed at 48 CSS pixels. Cardinal and diagonal adjacency selects one of 47 masks; four exact pixel-stepped quarters handle straight edges, outer/inner corners, thin strips, T-junctions, crosses and isolated blocks. This precise geometry is code, not baked approximate imagegen borders. The same mask vocabulary serves mountain, cave-wall and forest materials. Existing blocked interior overworld cells display forest; mountains are restricted to the perimeter. Collision, map coordinates and saved layout JSON are unchanged. Grass/path/water border artwork remains a later pass.

The map renders `EquippedPlayerAvatar`, shared with combat, at 40×72 CSS pixels. Identity, skin/hair/eye palettes, equipment and visual overrides all come from the same player projection. No alternate map character or animation rig is introduced.

Battle environment is server-frozen from the campaign encounter zone, published as the optional `battleEnvironment` enum. New cave fights select the cave image; overworld/classroom fights use grassland. Older saved fights without this field retain the grassland fallback; no active room migration occurs.
